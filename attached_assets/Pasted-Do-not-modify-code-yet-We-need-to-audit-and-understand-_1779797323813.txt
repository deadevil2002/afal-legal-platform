We need to audit and understand the current procurement workflow before changing anything.

Context:
The correct business flow should be:

1. Requester creates a procurement request/RFQ with product/service description and optional attachments.
2. The request goes to Procurement.
3. Procurement should create supplier form links using Generate Supplier Link.
4. The supplier form link should include the requester’s product/service description automatically, so the supplier knows what they are quoting for.
5. Procurement can send links to multiple suppliers.
6. Each supplier submits:
   - Commercial Registration attachment + CR number
   - Saudi Accreditation Center attachment + accreditation number
   - ZATCA number
   - Company/establishment name
   - Phone
   - Email
   - Contact person name
   - National Address attachment + national address text
   - IBAN attachment + IBAN text
   - Quotation price excluding VAT
   - VAT should be calculated automatically
   - Payment terms
   - Notes optional
   - Extra quotation/supporting attachments if needed
7. Supplier responses should appear to Procurement under the request.
8. Procurement reviews supplier responses and chooses which supplier quotations to send to the requester.
9. The selected supplier responses/quotations should be converted or represented as quotation attachments/PDF-style cards.
10. Procurement presses Send Quotations to Requester.
11. Requester sees the submitted supplier quotations and selects one, or rejects all.
12. If requester rejects all, the request returns to Procurement to find more suppliers.
13. If requester approves one quotation, the workflow continues to budget approval.
