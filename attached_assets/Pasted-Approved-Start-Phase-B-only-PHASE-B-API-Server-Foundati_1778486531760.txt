Goal:
Prepare the backend/API foundation needed for public supplier links and supplier form submission.

Context:
The supplier does NOT have an app account.
Supplier will receive a public link generated by Procurement.
Supplier opens the link and submits supplier quotation data.
Because supplier has no Firebase Auth login, writes must go through a secure backend/API route using Firebase Admin SDK.
